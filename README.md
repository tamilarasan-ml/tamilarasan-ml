# 🏆 AI Product Portfolio

## 💳 Payment Exception Resolution Copilot

**AI-powered ISO 20022 payment exception triage and resolution assistant.**

Designed as an AI Product Manager portfolio project to explore how AI can support payment operations while keeping critical business decisions governed.

### Product capabilities

- ISO 20022 `pain.001` validation failure classification
- AI-assisted exception analysis
- Retrieval of similar historical resolutions
- Governed deterministic routing
- AI-generated resolution notes
- Auditable decision path
- Ground-truth evaluation

### Technology

`Python` `LangGraph` `Azure AI Foundry` `GPT-5.4-mini` `Azure AI Search` `RAG` `Streamlit`

# 🧪 Side Project

## 📚 DOCMIND — Enterprise RAG Knowledge Assistant

**An enterprise document knowledge assistant built with Azure AI.**

DOCMIND explores how enterprise documents can be transformed into a grounded conversational knowledge experience, emphasizing retrieval quality, answer grounding and traceable sources.

### Core capabilities

- PDF document processing and text extraction
- Document chunking and embedding generation
- Retrieval using Azure AI Search
- LLM-powered grounded responses
- Page-level citations for source traceability
- Out-of-scope question handling
- Automated evaluation of answer quality

### Technology

`Python` `Azure AI Foundry` `Azure AI Search` `GPT-5-mini` `text-embedding-3-small` `RAG`

**Repository:** [Explore DOCMIND on GitHub](https://github.com/tamilarasan-ml/docmind-rag)

*DOCMIND is the only featured side project in this version. Additional projects will be added later.*
